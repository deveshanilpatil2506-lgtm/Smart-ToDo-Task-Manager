# Smart To-Do Task Manager

A Python desktop application built with Tkinter and SQLite.

## Features
- Add, edit, complete, and delete tasks
- High, Medium, and Low priorities
- Optional deadlines with date validation
- Search tasks by title
- Filter by priority and completion status
- Dashboard statistics and overdue alerts
- Persistent SQLite storage

## Requirements
- Python 3
- Tkinter (usually included with standard Python installations)

## How to Run
1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run:

   python main.py

The application creates or initializes its local database as needed.
